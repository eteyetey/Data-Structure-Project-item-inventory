아이템 인벤토리 제작 프로젝트

1.기본적으로 인벤토리라면 무조건 있어야 하는 기능
인벤관련 : 추가/삭제/이동/정렬/검색/수량변경
아이템 관련 : 이름/범주/희귀도/내구도/id(파일에 저장)
게임관련 : 아이템 사용
(게임을 만드는것이 아니기 때문에 아이템 사용 외에 다른 기능은 넣지 않을것임)

2.추가할 기능
터미널 상에 출력/파일입출력을 통한 저장관리/상자와 같은 인벤 외 저장공간에 넣기/꺼내기(따로 파일로 관리)

3.사용할 자료구조
이중 연결리스트 : 따로 구현할 생각, 아이템의 이동이 많기 때문에 효율적임.
맵 : 아이템의 ID에 기반해서 빠른 아이템 검색
스택 : 최근에 했던 작업 되돌리기(추가할지 말지 고민, 삭제는 되돌릴 수 없게하는게 맞는듯)
큐 : 상자에서 인벤토리로 옮길 아이템을 선택할 시 대기열 역할
우선순위 큐 : 희귀도,내구도 등 우선순위가 정해지는 값을 기준으로 우선선택해야할 경우 사용
셋 : 범주 관리, 새 아이템이 기존 범주에 있다면 범주 추가 X , 새 아이템이 기존 범주에 없는 새 출시 범주라면 범주 추가
벡터:거의사용안함

4.아이템 클래스

4-1.사용형 아이템 : 무조건 한개당 한번 사용하면 소모되는 아이템임
4-2.내구도형 아이템 : 아이템마다 일정치 내구도가 있고, 내구도를 모두 소모하면 사라지는 아이템임
4-3.영구 사용 아이템 : 내구도가 없이 영구적으로 사용 가능한 아이템임
4-4.사용 불가 아이템 : 그냥 수집용으로 있는 아이템같이 사용도 안되고 내구도도 없는 아이템

5.파일 구조
Item_Inventory/
├── main.cpp
│
├── Item.h
├── Item.cpp
│
├── Inventory.h
├── Inventory.cpp
│
├── Storage.h
├── Storage.cpp
│
├── ItemLinkedList.h
├── ItemLinkedList.cpp
│
├── Action.h
├── Action.cpp
│
├── FileManager.h
├── FileManager.cpp

main : 프로그램의 실행부
item : 아이템 객체와 사용
Inventory : 실제 인벤토리의 기능
Storage : 상자(외부 저장공간) 기능
ItemLinkedList : 아이템이 저장될 공간, Inventory 와 Storage 는 이 자료구조를 기반으로 저장기능을 수행
Action : 행동 되돌리기와 같은 기능을 위함
FileManager : Inventory 와 Storage 에서 사용할 파일 입출력을 담당
